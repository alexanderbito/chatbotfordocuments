2. What BotClarify does

BotClarify is a question-and-answer tool for a company's own documents. An administrator uploads files. We read the text out of them, index it, and let your people ask questions in a chat. The answer is drawn from your documents, and every answer names the file it came from.

We accept PDF, DOCX and TXT files, up to 25 MB each. For scanned PDFs with no text layer, we use optical character recognition to read the page.

Every answer names the source file it drew on. That is there so you can check it. If an answer will be used for anything that matters, open the source document and verify it before you act.
